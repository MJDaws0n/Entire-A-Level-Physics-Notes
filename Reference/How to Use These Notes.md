# How to Use These Notes

Start at [[00 Course Index]]. Each PowerPoint has one lesson note in the matching topic folder.

- Follow the **Core notes** in lesson order.
- Use the **Equations** section for checked LaTeX formulae and symbol relationships.
- Follow the numbered **Method** rather than memorising calculator button sequences.
- Open linked terms in [[Glossary]] without leaving the lesson.
- Use [[Formula Sheet]], [[Constants and Conversions]] and [[Mathematical Skills]] for course-wide revision.
- Use [[OCR Specification Checklist]] to check that every current OCR module outcome has a route into the vault.
- Use [[Equation Solving Method]], [[SI Units, Prefixes and Significant Figures]], [[Graphs, Gradients and Data Skills]], [[Radians]], and [[Practical Skills and Uncertainties]] whenever a lesson assumes those skills.
- Expand **Additional examinable detail from the slides** for factual source material, PowerPoint calculation steps, tables and useful speaker-note detail that did not fit the concise summary.
- Expand **Source slide route** when you want to match the note back to the original teaching sequence.

The source PowerPoints remain unchanged. The notes correct clear physics, arithmetic and unit mistakes; see [[Corrections and Clarifications]]. The deck-by-deck classification is recorded in [[Content Coverage Audit]].
