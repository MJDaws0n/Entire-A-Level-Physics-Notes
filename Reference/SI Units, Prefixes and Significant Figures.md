# SI Units, Prefixes and Significant Figures

[[00 Course Index|Course index]] · [[Equation Solving Method]]

## Common prefixes

| Prefix | Symbol | Factor |
|---|---:|---:|
| tera | T | \(10^{12}\) |
| giga | G | \(10^9\) |
| mega | M | \(10^6\) |
| kilo | k | \(10^3\) |
| centi | c | \(10^{-2}\) |
| milli | m | \(10^{-3}\) |
| micro | µ | \(10^{-6}\) |
| nano | n | \(10^{-9}\) |
| pico | p | \(10^{-12}\) |

Replace a prefix with its factor before calculating:

$$35\,\mathrm{ms}=35\times10^{-3}\,\mathrm{s}=0.035\,\mathrm{s}$$

For powers, raise the conversion factor too:

$$1\,\mathrm{cm^2}=(10^{-2}\,\mathrm{m})^2=10^{-4}\,\mathrm{m^2}$$

$$1\,\mathrm{cm^3}=(10^{-2}\,\mathrm{m})^3=10^{-6}\,\mathrm{m^3}$$

Keep extra digits during working. Round only the final answer and give a unit. Significant figures usually follow the least precise input, but uncertainty can justify a different choice.
