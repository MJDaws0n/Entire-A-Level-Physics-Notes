## Core notes

### 12.2 Interference

*Source slide 1.*

- Phase difference is measured as an angle.
- Therefore it is dimensionless.
- This can be done in degrees or radians.

### Warning

*Source slide 4.*

- This is a tricky lesson for most students.
- You will need to go over this material several times to master this topic.
- If you need clarification at any point please ask.

### Coherence

*Source slide 6.*

- If two waves have a constant phase difference then they are called [[Glossary#Coherent|coherent]].
- If waves are coherent then they produce stable and periodic interference patterns.
- If waves are not coherent then they will still interfere but in a unstable and non-periodic fashion.
- A filament lamp produces non-coherent light as it emits a range of frequencies that have an ever changing phase differences.

### Path Length and Path Difference

*Source slide 7.*

- The distance the wave travels is the path length.
- This can be measured in multiple of the [[Glossary#Wavelength|wavelength]] of the wave.
- Path difference is difference in distance that a wave travels.

### Path and Phase Difference

*Source slide 8.*

- We have two sources that emit a single wavelength of light which are coherent with each other.
- A minimum occurs when the path difference is an odd number of half wavelengths.
- A maximum occurs when the path difference is a multiple of the wavelength.

### Periodic Interference Pattern

*Source slide 9.*

- Both waves travel the same distance and constructively interfere.
- There is one wavelength difference and the waves constructively interfere.
- All wave types can superpose, but a stable interference pattern requires coherent sources.

## Equations

### Superposition and interference

$$\Delta x=n\lambda$$

Constructive interference.

$$\Delta x=\left(n+\frac{1}{2}\right)\lambda$$

Destructive interference.

$$\lambda=\frac{ax}{D}$$

Double-slit relationship for small angles.

See [[Formula Sheet]] for the complete course formula set.

## Method

1. Add displacements algebraically at the same place and time.
2. For stable fringes, sources must be coherent: same frequency with constant phase difference.
3. In the double-slit formula, use slit separation \(a\), fringe spacing \(x\), and screen distance \(D\).

## Common mistakes

- Fringe spacing is the distance between adjacent bright fringes, not from the centre to an arbitrary fringe unless divided by fringe number.
