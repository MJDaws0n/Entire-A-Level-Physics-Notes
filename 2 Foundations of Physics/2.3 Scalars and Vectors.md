## Core notes

### Scalars

*Source slide 3.*

- Scalars have a magnitude (size) but no direction.
- This is by no way an exhaustive list.

### Addition, Subtraction, and Scalars

*Source slide 4.*

- Addition and subtraction works in the usual way with scalars.
- For adding and subtracting the quantities need the same units.
- For example: Calculate 1.0 minute + 30 s

### Multiplication and Scalars

*Source slide 5.*

- Multiplication with scalars is also straightforward you just need to keep track of the units.
- The easiest way to do this is to always write the unit with the number.
- This is best practice and is non-negotiable.

### Vectors

*Source slide 8.*

- Vectors have a magnitude (size) and a direction.

## Equations

### Vectors and components

$$F_x=F\cos\theta$$

Component adjacent to the stated angle.

$$F_y=F\sin\theta$$

Component opposite the stated angle.

$$R=\sqrt{R_x^2+R_y^2}$$

Magnitude from perpendicular components.

$$\theta=\tan^{-1}\!\left(\frac{R_y}{R_x}\right)$$

Direction from perpendicular components; check the quadrant.

### Base and derived units

$$1\,\mathrm{N}=1\,\mathrm{kg\,m\,s^{-2}}$$

The newton in SI base units.

$$1\,\mathrm{J}=1\,\mathrm{kg\,m^2\,s^{-2}}$$

The joule in SI base units.

$$1\,\mathrm{W}=1\,\mathrm{kg\,m^2\,s^{-3}}$$

The watt in SI base units.

$$1\,\mathrm{Pa}=1\,\mathrm{kg\,m^{-1}\,s^{-2}}$$

The pascal in SI base units.

See [[Formula Sheet]] for the complete course formula set.

## Method

1. Choose positive directions and draw a labelled sketch.
2. Resolve every vector along the same pair of perpendicular axes.
3. Add components with signs, then find the magnitude and direction of the resultant.
4. Start from the defining equation for the derived quantity.
5. Replace each named unit by base units and cancel powers carefully.
6. Use dimensional consistency to check an equation, not to prove that it is physically correct.

## Common mistakes

- A negative component means the vector points opposite to the chosen positive direction.
- State directions with the final magnitude; a magnitude alone is not a complete vector answer.
- Do not add quantities expressed in different units until they have been converted.
