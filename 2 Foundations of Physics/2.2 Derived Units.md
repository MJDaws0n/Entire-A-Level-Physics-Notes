## Core notes

### Mathematical Representation

*Source slide 3.*

- Here is a quick note on a difference from GCSE to A level.
- Instead of writing the units of speed as m s⁻¹ we will use indices notation.
- This might seem a pointless exercise yet this is a clearer method that you used at GCSE.
- For example for the units of specific heat capacity in GCSE you would have written something like, J / kg K or J / (kg K) yet now we would write, J kg-1 K-1 which is clear.

### Derived Units

*Source slide 5.*

- We use the International System (SI) of units in physics.
- For A level physics you will need to be able to decompose (split up) derived units into their basis form.
- This might seem like a pointless exercise yet it is the ground work for a very powerful tool that physicists use called dimensional analysis.

### Measuring Temperature

*Source slide 6.*

- We can measure temperature with the Kelvin (K) scale.
- This is based on the motion of the particles.
- We can measure temperature with the Celsius (°C) scale.
- This scale is based on change of state for water.

## Equations

### SI units, prefixes and conversions

$$Q_{\mathrm{base}} = Q_{\mathrm{prefixed}}\times 10^n$$

Replace the prefix by its power of ten.

$$T\,(\mathrm{K}) = \theta\,({}^{\circ}\mathrm{C}) + 273.15$$

Convert Celsius temperature to kelvin.

### Base and derived units

$$1\,\mathrm{N}=1\,\mathrm{kg\,m\,s^{-2}}$$

The newton in SI base units.

$$1\,\mathrm{J}=1\,\mathrm{kg\,m^2\,s^{-2}}$$

The joule in SI base units.

$$1\,\mathrm{W}=1\,\mathrm{kg\,m^2\,s^{-3}}$$

The watt in SI base units.

$$1\,\mathrm{Pa}=1\,\mathrm{kg\,m^{-1}\,s^{-2}}$$

The pascal in SI base units.

See [[Formula Sheet]] for the complete course formula set.

## Method

1. Write the prefix as a power of ten before doing the calculation.
2. Convert every value to coherent SI units, then substitute.
3. Carry extra calculator digits and round only the final answer.
4. Start from the defining equation for the derived quantity.
5. Replace each named unit by base units and cancel powers carefully.
6. Use dimensional consistency to check an equation, not to prove that it is physically correct.

## Common mistakes

- A capital letter can change a prefix: \(\mathrm{m}\) is milli but \(\mathrm{M}\) is mega.
- For squared or cubed units, the conversion factor must also be squared or cubed.
- Do not add quantities expressed in different units until they have been converted.
