## Core notes

### Centre-seeking Forces

*Source slide 3.*

- When we rotate an object around a point it must be accelerating as it is changing its direction.
- Remember, [[Glossary#Acceleration|acceleration]] is a [[Glossary#Vector|vector]] related to the change of [[Glossary#Velocity|velocity]] (speed and direction) in a certain time.
- If an object is accelerating it must have a [[Glossary#Force|force]] being applied to it.
- If a force was not being applied it would continue with uniform motion until a force was applied.
- The force keeping the object in a circular motion is called the centripetal (centre seeking) force.

### Increasing the Radius and Velocities

*Source slide 5.*

- This is because as you increase the radius you are increasing the distance travelled.

### Centripetal Acceleration

*Source slide 6.*

- [[Glossary#Centripetal Acceleration|Centripetal acceleration]] is the acceleration for an object which is travelling in a circular path at constant speed.
- The centripetal acceleration acts as the centripetal force and is directed to the centre of the circle.
- We can see that velocity is proportional and radius is inversely proportional.

### Deriving Centripetal Acceleration

*Source slides 9–10.*

- There are many ways, from rigorous to less so, to derive the equation for centripetal acceleration.
- Here I will show you the simplest way to do so which requires some hand waving to get to the result.
- Imagine an object steadily moving around a circle.
- Now consider the velocity vector for the object.
- It’s position can be represented by a vector of constant length that changes angle.

## Equations

### Radians and angular motion

$$s=r\theta$$

Arc length; \(\theta\) must be in radians.

$$\omega=\frac{\Delta\theta}{\Delta t}=\frac{2\pi}{T}=2\pi f$$

Angular velocity.

$$v=\omega r$$

Linear speed.

## Method

1. Convert angles to radians before using rotational equations.
2. Use the same time interval when connecting angular and linear motion.

## Common mistakes

- Angular speed is shared by points on a rigid rotating object, but linear speed increases with radius.
